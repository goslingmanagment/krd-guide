# Краснодар после заката

Статический гид по ресторанам, барам и ночным местам Краснодара.
Карточки можно добавить в план вечера и скопировать маршрут; выбор сохраняется
в `localStorage` браузера. Материалы — снимок на август 2026 года, дата проверки
указана на странице. Перед обновлением рекомендаций нужно перепроверить факты.

[Сайт на GitHub Pages](https://goslingmanagment.github.io/krd-guide/).

## Локальный просмотр

Весь сайт находится в [index.html](index.html): разметка, стили, JavaScript,
SVG-иллюстрации и шрифты. Сборка, зависимости и сервер приложения не нужны.
Из корня репозитория можно запустить локальный статический сервер:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8000/`. При изменениях страницы проверить узкий и
широкий экран, добавление и удаление мест, копирование и очистку плана.

## Публикация

GitHub Pages настроен на корень ветки `main`. Изменения в `main`, включая
документацию, могут запустить публикацию. Перед слиянием нужно учитывать это
как изменение опубликованного сайта.
